- **It rebranded as Velocity DEX / Velocity Exchange** (announced 2026-07-01) and reopened
  on or about **2026-09-29/30** after OtterSec and Asymmetric Research audits, with a
  Tether credit line ($127.5M), USDT instead of USDC as the quote asset, and co-founder
  Cindy Leow stepping down. Sources: https://thedefiant.io/news/defi/drift-protocol-rebrands-to-velocity-dex-ahead-of-relaunch ,

  https://www.chaincatcher.com/en/article/2293121 (2026-09-30, "restarting today").
- **It is a new deployment, not an upgrade.** Velocity's own migration guide: "an entirely

  https://docs.velocity.exchange/developers/migrate-from-drift
- **Drift's API is gone.** Live DNS (Cloudflare DoH) on 2026-10-22: `data.api.drift.trade`

  `mainnet-beta.api.drift.trade` are NXDOMAIN. www.drift.trade still serves a marketing page

- **The venue is tiny now.** Live `/stats/markets`: 5 perps (SOL, BTC, ETH, HYPE, ZEC),

## 2. Leaderboard

`GET https://data.velocity.exchange/stats/leaderboard` (OpenAPI tag "Stats"; live 200,
no auth). Query: `page` (1-based integer, default 1), `limit` (1-100, default 100),
`sort` (`pnl` | `volume`, default `pnl`), `start` / `end` (`YYYY-MM-DD` UTC), `symbol`.
Response: `{"success":true,"data":{"leaderboard":[{"authority","volume","pnl","rank"}]}}`
with `pnl`/`volume` as JSON floats in USDT (e.g. `20.494687000000056`: needs
`leaderboard_figure` rounding exactly like Polymarket's floats).

Live results 2026-10-22:

| Query | Rows | Rows with pnl > 0 |
|---|---|---|
| default (7 days) | 62 | 23 |
| `start=2026-10-21&end=2026-10-22` | 25 | 6 |
| `start=2026-09-29&end=2026-10-22` | 100 (page 1) | 35 |
| `start=2026-01-01&end=2026-10-22` | 74 on page 1 [VERIFY why fewer than the since-relaunch query] | 73 |
| `start=2025-01-01&end=2025-12-31` | 0 (Drift-era data not carried over) | - |

Mapping to `LeaderboardPeriod`: DAY = `start=end=today` or yesterday..today, WEEK =
default, MONTH = 30 days back, ALL = `start=2026-09-01`. That is four calls, each a
single page at current size. `GET /stats/leaderboard/{authority}?start&end` returns one
authority's `pnl`, `volume` and `rank.{pnl,volume}`.
Rows are keyed by **authority** (wallet), aggregated across its subaccounts [VERIFY], with
no names. There is no ROI or account value: Koine would show PnL and volume only, or
compute account value itself from `/user/{accountId}`.
Also present: `/stats/maker-leaderboard` and `/stats/taker-leaderboard` (current-month
volume rankings, not useful for discover). The app's `/leaderboard` path redirects to `/`
(no leaderboard page in the UI) [VERIFY].

Rate limits: the docs say the spec "declares no rate limit, no quota header, and no 429
... Treat that as undocumented rather than unlimited". 15 sequential calls returned 200;

Can Koine rebuild a verified record? From relaunch onward, nearly: every fill, fee,
funding payment, deposit, withdrawal and liquidation is a public event with a tx
signature, and state is public for reconcile. Caveats for `reconcile.py`:

1. **USDT deposit interest** accrues continuously via `cumulativeDepositInterest` with no

## 5. Address and subaccount model

- Addresses are Solana base58 public keys (32-44 chars, alphabet without 0/O/I/l),
  **case-sensitive**: lowercasing corrupts them. `watchlist.ADDRESS_RE`
  (`^0x[0-9a-f]{40}$`), `normalize_address` (`.lower()`), `short_address`,
  `LeaderboardEntry.address` ("lowercased 0x address") and the Hyperliquid claim regex all
  assume EVM.
- An authority (wallet) owns subaccounts 0..N; each is a User PDA derived from
  `(program_id, authority, subAccountId)` with its own collateral ("Collateral is never
  shared between subaccounts"). Vault-managed accounts have the vault PDA as authority;
  delegates can trade an account but never withdraw.
- What to key a watch on: the **authority** (what the leaderboard returns and what a user
  would paste), fanned out to its subaccounts via `/authority/{id}/accounts`, with one
  Koine account per subaccount or one per authority aggregating subaccounts (internal
  transfers then cancel). New subaccounts must be discovered on each sync.
- Opt-out proof needs Solana `signMessage` (ed25519 over UTF-8 bytes) instead of EIP-191.

## 6. Streaming

- DLOB `wss://dlob.velocity.exchange/ws`: `orderbook`, `orderbook_indicative`, `trades`,
  `priorityfees`; heartbeat every 5 s; no auth. Live: connected in 0.5 s from the US and
  acknowledged trades subscriptions on all 5 perps; no trade arrived in ~7 minutes (thin
  markets). Per docs the trades stream is per market, so watched-account detection would
  subscribe to all markets and filter by `taker`/`maker` [VERIFY payload fields].
- Alternative: Solana RPC `logsSubscribe` on the program and Anchor event decoding
  (needs a paid RPC such as Helius/Triton; the app itself uses helius-rpc and rpcpool).
- Either way this is a new `StreamMode` (market-wide feed filtered locally), unlike
  Hyperliquid's per-user `userFills` with a 10-users/IP cap.

## 8. Fit with contract v2 and the new shared work

Maps directly:

- `AssetVenueConnector`: perps only, quote asset `USDT` (decimals 6), base decimals 9 per
  `/stats/markets.precision`; fills -> legs with fee in USDT; `fundingPayment` -> funding
  events; deposits/withdrawals -> external flow events; liquidations -> events with their
  own fees; `settlePnl` is an internal re-classification (no ledger leg, or a zero-sum pair).
- `Page` cursors: opaque `nextPage` maps onto `resume_cursor`; monthly archive gives a clean
  backfill walk.
- `AssetMarketData`: quotes from DLOB `/l2`, funding from `/market/{symbol}/fundingRates`,
  daily closes from candles.
- `fetch_leaderboards`: four date-range calls; `roi` and `account_value` stay `None`.

New or awkward:

1. **Non-EVM addresses** (shared): a per-venue address validator/normalizer in the profile
   (EVM lowercase vs base58 exact-case), `LeaderboardEntry.address` docstring, watchlist
   regex, `short_address`, URL routes, `watch_optouts` keys and any unique index that
   assumes lowercase. Also needed for any other Solana venue.
2. **Authority -> subaccount fan-out** (shared with Hyperliquid sub-accounts, which Koine
   treats via `master`): one watched address becomes N venue accounts discovered over time.
3. **Opt-out signature** (shared): ed25519 `signMessage` verification (PyNaCl or
   `cryptography`) alongside EIP-191.
4. **USDT** as quote asset (USDT/USD price, not 1.0; live oracle 0.9987).
5. **Optional RPC dependency**: tick/step sizes and a non-BETA account state need a Solana
   RPC and Anchor IDL decoding (borsh) of `User` / `PerpMarket`; the Data API alone covers
   history. Avoidable at first by pinning ticks in the profile and using `/user/{id}`.
6. **Streaming**: market-wide DLOB `trades` filtered locally (new `StreamMode`), or RPC logs.
7. **Reconcile tolerance** for deposit interest; socialized-loss handling.
8. Pre-relaunch (Drift) history would need an archival-RPC indexer of the old program: out
   of scope.

Effort if pursued: M-L (connector + market data M; address-model generalization is the
shared L-sized part, and it is the same work any Solana venue forces).

## 9. Risks

- Venue viability: weeks-old relaunch after a $285M exploit, 5 markets, ~$50k/day volume,
  62 weekly leaderboard traders, and a recovery-token overhang. A watchlist of its traders
  would be thin and their records short.
- Terms: explicit API coverage plus a commercial / third-party-benefit ban; US exclusion.
- Undocumented rate limits; BETA account endpoints; the Data API host already moved once
  (Drift -> Velocity) and the old one was simply switched off, so a host or shape change
  without notice is a demonstrated risk.
- Address-model change touches shared watchlist code and tests.
- The program source is not yet public ("The Velocity program is not open source yet"), so
  event semantics rely on docs; docs repo last commit 2026-09-15 predates the relaunch.
